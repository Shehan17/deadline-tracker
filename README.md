# Deadline Tracker

Deadline Tracker is a simple Windows desktop application built with C# and WPF.  
It helps users track important deadlines with live countdown timers.

## Features

- Add multiple deadlines
- Categorize deadlines
- Live countdown timer
- Mark deadlines as completed
- Delete deadlines
- Local JSON data storage

## Tech Stack

- C#
- .NET
- WPF
- JSON

## Planned Features

- Windows startup option
- Desktop notifications
- Dark mode
- System tray support
- Deadline priority levels
